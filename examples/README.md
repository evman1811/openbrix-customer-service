# Example replies

Drop past emails + the reply the team sent here, one per file (`.txt`, `.md` or `.eml`).
Claude copies their tone, length and sign-off. 20-30 good examples is plenty.

Format that works best:

```
CUSTOMER:
<their email>

REPLY:
<what we sent>
```

**These files are git-ignored** because they contain real customer details and this repo is public.
Keep them on the machine that runs the bot, or remove names/emails/addresses before committing one.
